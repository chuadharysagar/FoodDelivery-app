# 🍔 Food Delivery Platform                   [🔗 Live Demo](https://fooddelivery-app-frontend-psry.onrender.com)

A full-stack food delivery platform with a responsive UI, secure authentication, and seamless ordering experience.

## 🚀 Features

- 📱 **User-Friendly Interface**: Browse restaurants, order food, and pay via Stripe or cash on delivery.
- 🔐 **Secure Authentication**: JWT-based authentication with session management.
- 📊 **Admin Dashboard**: Manage restaurants, menu items, and oversee orders efficiently.
- 🔍 **Real-Time Search**: Advanced filtering for quick food discovery, reducing search time by 40%.
- ⭐ **Top Restaurant Rankings**: Ranked based on ratings and sales.

## 🛠️ Tech Stack

- **Frontend**: React.js
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Payments**: Stripe Integration

## 🔧 Installation

1. Clone the repository:
   ```bash
   https://github.com/chuadharysagar/FoodDelivery-app.git
   ```
2. Navigate to the project directory:
   ```bash
   cd FoodDelivery-app
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Set up environment variables (create a `.env` file and add required keys).
5. Run the development server:
   ```bash
   npm run dev
   ```

## 🎯 Usage

- Sign up or log in to browse restaurants.
- Add food items to your cart and proceed to checkout.
- Choose payment method: Stripe or cash on delivery.
- Track your order in real-time.
- Admins can onboard new restaurants and manage orders.
